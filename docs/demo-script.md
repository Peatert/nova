# Демо-видео Nova — сценарий на 2:30

Цель: за 2,5 минуты показать рекрутеру/техлиду, что это не «формочки», а система с настоящими банковскими решениями.
Принцип: **каждая сцена = одна сильная мысль**. Не читать код, показывать результат и называть решение.

## Сильный дубль сцены 7 (по желанию, +20 с)

Показать, что цепочку правда нельзя подделать:

```powershell
docker exec -it nova-db psql -U nova -c "UPDATE audit.audit_log SET target = 'hacker' WHERE id = 5;"
```

Обновить страницу «Аудит» → **✗ нарушена, первая испорченная запись: #5**.
Вернуть как было нельзя (хэш уже не сойдётся) — поэтому делать **только на копии базы** или в конце записи,
а потом пересоздать данные: `dotnet run --project src/Nova.Seeder -c Release -- --reset`, затем `-- --demo`.
`--reset` очищает и сотрудников: 2FA владельцу придётся включить заново (сценарий в `Nova.Api.http`).
